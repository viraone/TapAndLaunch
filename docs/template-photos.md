# Template photos

Photos used by starter templates live in `public/templates/` and are served from the main site
(`https://tapandlaunch.com/templates/<name>.jpg`, see `templatePhoto()` in `src/lib/apps/templates.ts`). They are resized
(1600px wide for banners, 900px for gallery tiles) and compressed. All are from Unsplash under the Unsplash License: free for
commercial use, no attribution required. Credit is kept here so we know where each came from.
